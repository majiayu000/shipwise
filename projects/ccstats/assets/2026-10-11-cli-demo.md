# ccstats 0.11.0 isolated CLI demo

Verified on 2026-10-11 on macOS arm64. The public [GitHub release](https://github.com/majiayu000/ccstats/releases/tag/v0.11.0)
and [crates.io package](https://crates.io/crates/ccstats/0.11.0) agree on `0.11.0`.
A real Cargo install into a new installation root completed successfully with
Rust/Cargo 1.97.0 and two build jobs. Existing Cargo dependency caches were
available; this was not a pristine operating-system image or cold-cache test.
No global installation or shell configuration was changed.

This is **actual installed CLI output over synthetic Codex input**. It is not
real-user usage, model activity, billing evidence, or a benchmark. `gpt-5` is a
fixture label; no model/API call was made. No real session, credential, or prompt
was copied into the fixture or public materials.

## Install

The verification used new install and build directories:

```bash
demo_root=$(mktemp -d)
cargo install ccstats --version 0.11.0 --locked \
  --root "$demo_root/install" --target-dir "$demo_root/build" --jobs 2
"$demo_root/install/bin/ccstats" --version
```

Observed result:

```text
Installed package `ccstats v0.11.0` (executable `ccstats`)
ccstats 0.11.0
```

Installed binary SHA-256: `ed89614b1b9ae843d2ed862f825160f7e22a8fdbd8a80c3410c4e8bd5166cf7d`.
This hash identifies this locally compiled binary, not a GitHub release archive.

## Reproduce the isolated input

The runtime received a new home, Codex directory and XDG directories through
`env -i`; it inherited no ambient credentials or source-root overrides. The
selected source was Codex and pricing/network refresh was disabled. The CLI
reported scanning exactly one Codex file.

```bash
mkdir -p "$demo_root/home/.codex/sessions"
cat > "$demo_root/home/.codex/sessions/demo.jsonl" <<'JSONL'
{"timestamp":"2026-10-11T00:00:00Z","type":"session_meta","payload":{"id":"00000000-0000-4000-8000-000000000001","cwd":"/demo/ccstats","originator":"codex_cli_rs","cli_version":"synthetic-fixture"}}
{"timestamp":"2026-10-11T00:00:00Z","type":"turn_context","payload":{"model":"gpt-5","cwd":"/demo/ccstats"}}
{"timestamp":"2026-10-11T00:00:01Z","type":"event_msg","payload":{"type":"token_count","info":{"total_token_usage":{"input_tokens":100,"cached_input_tokens":20,"output_tokens":30,"reasoning_output_tokens":10,"total_tokens":130},"last_token_usage":{"input_tokens":100,"cached_input_tokens":20,"output_tokens":30,"reasoning_output_tokens":10,"total_tokens":130},"model":"gpt-5"}}}
JSONL
env -i PATH=/usr/bin:/bin:/usr/sbin:/sbin \
  HOME="$demo_root/home" CODEX_HOME="$demo_root/home/.codex" \
  XDG_CONFIG_HOME="$demo_root/home/.config" \
  XDG_CACHE_HOME="$demo_root/home/.cache" \
  XDG_DATA_HOME="$demo_root/home/.local/share" \
  NO_COLOR=1 TERM=dumb TZ=UTC LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8 COLUMNS=120 \
  "$demo_root/install/bin/ccstats" daily --since 20261011 --until 20261011 \
  --source codex --no-cost --offline --timezone UTC --no-cache
```

Fixture SHA-256: `2bf4ad7304915c978096069e071cf5adfffcae15ab676d944097794d1f4e003b` (including its final newline).
The fixed date range makes this replay work after the capture date. On
2026-10-11 the normal `today --source codex --no-cost --offline --timezone UTC`
quickstart also exited 0 and reported `Today: 130 tokens.`

Input tokens include cached input; output tokens include reasoning output.
The fixture therefore has 100 + 30 = 130 total tokens, not 140. The table
separates the subsets without adding them twice.
